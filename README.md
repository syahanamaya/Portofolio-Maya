# Portfolio — Syahana Maya Sya'bana

Website portofolio responsif dengan HTML, CSS, dan JavaScript.

## Isi
- `index.html` — struktur dan konten website
- `style.css` — layout, warna, komponen, dan responsive design
- `script.js` — menu mobile, tahun footer, dan tombol salin link
- `profile-photo.png` — foto profil pada bagian hero

## Cara menjalankan
1. Ekstrak folder ZIP.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.
3. Untuk menerbitkan melalui GitHub Pages, unggah ketiga file ke repository yang dipilih dan aktifkan GitHub Pages dari pengaturan repository.

## Sebelum dipublikasikan
- Pastikan URL profil GitHub pada tombol kontak benar.
- Tambahkan email profesional atau tautan LinkedIn bila ingin menampilkannya.
- Ganti ilustrasi proyek dengan screenshot asli yang aman dibagikan, terutama untuk proyek magang/internal.
- Pastikan nyaman menampilkan foto profil ini secara publik sebelum menerbitkan website.
- Tambahkan tautan repository atau demo untuk tiap proyek jika memang tersedia.
- Tinjau kembali deskripsi proyek agar sesuai dengan kontribusi yang benar-benar dilakukan.

Visual dashboard dan portal pada halaman proyek adalah ilustrasi CSS, bukan screenshot aplikasi asli.
